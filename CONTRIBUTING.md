# Contributing to mcp-plugin-tessera

Thank you for your interest in contributing to `mcp-plugin-tessera`!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JaDi03/mcp-plugin-tessera.git
   cd mcp-plugin-tessera
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run TypeScript compiler in watch mode:**
   ```bash
   npm run build
   ```

4. **Run linter and tests:**
   ```bash
   npm run lint
   npm test
   ```

## Pull Request Guidelines

- Ensure all code is written in 100% professional English.
- Do not commit secrets or `.env` files.
- Ensure `npm run lint` and `npm run build` pass with zero errors.
